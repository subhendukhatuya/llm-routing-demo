Deployment Guide

Publishing to GitHub Pages

This website is entirely self-contained in a single file. Save it as index.html and push.

# 1. Save this code as index.html and initialize repo
git init
git add index.html
git commit -m "Add LLM Router benchmark demo page"

# 2. Push to your GitHub repository
git branch -M main
git remote add origin https://github.com/your-username/llm-routing-demo.git
git push -u origin main

# 3. Enable Pages under Repository Settings -> Pages -> Source: main branch / root
